            Sistema de control pra las Netbook del colegio

Este proyecto esta disenado para el equipo directivo de la Escuela tecnica N^5 de merlo. nuestro objetivo principal es que les sea de urilidad nuetra web para podes tener registros de las compus prestadas a estudiantes y alumnos que la necesiten para su uso pedadogico.

En un futuro le podriamos agregar un scaner como el de los supermercados para los productos pero en nuestro caso es para scanear el codigo de barra de las netbook y ser mas sencillo cargarlas a la web .
